# 水晶材质与字体合成

## 目标与边界

参考图的关键不是单个“透明度”数值，而是同一画面内有不同厚度的半透明层：Card 底板最轻，图标格填充稍实，图标格和 Card 外沿用更亮的线框分离边界，图标与文字保持完整可读性。当前 Win32 宿主继续使用 `WS_EX_LAYERED + UpdateLayeredWindow` 和自有 32 位预乘 Alpha DIB；不采样桌面、不做实时背景模糊，也不引入 DirectComposition、额外线程或逐帧动画。

## 固定材质参数

`ResolveCrystalMaterialStyle()` 是设置入口、渲染器和测试共同使用的唯一规格：

| 层 | Alpha | 合成语义 |
|---|---:|---|
| Card 底板 | 0.32 | 保存到实例 `appearance.opacity`，决定大面积桌面透出量 |
| 图标框填充 | 0.16 | 在底板上额外合成，不替换底板 Alpha |
| 图标框线框 | 0.54 | 1 DIP 亮线，独立于底板 Alpha |
| Card 外轮廓 | 0.52 | 1 px 抗锯齿亮边，独立于底板 Alpha |

水晶图标框相对每个 `itemRect` 内缩 3 DIP，圆角 9 DIP。Grid 中是一格一个框；List 中沿用一项一行的同一槽位几何。所有预设都由 `settings.showIconBackgroundFrame` 决定是否持续显示图标框；水晶只负责开关开启后的专属填充和线框 Alpha，关闭时仅保留 hover 反馈。Shell 图标最后按自身预乘 Alpha 全强度合成，Card 与图标框 Alpha 不会再次削弱图标。

圆角填充、图标框和 Card 外沿统一使用 `RoundedRectSpec` 的像素中心采样。实线框是完整的 1 DIP 内描边：外侧受圆角形状覆盖率裁切，内侧按 stroke width 截止，不再把笔画中心放在窗口或槽位边界上后裁掉外半条。相同规格在偶数和奇数宽高下都要求上/下、左/右及镜像圆角覆盖率一致。

图标框额外 Alpha 使用单次渲染期间的 8 位 coverage 缓冲，大小为 `surface.width * visibleBottom` 字节且只由水晶 Card 使用。所有外观的文字、Emoji、Pin、折叠箭头、网格/列表按钮、Todo 加号和复选框都使用独立的 32 位预乘内容缓冲；GDI 灰阶文字还会短暂创建一张同尺寸 32 位 mask DIB。内容 Alpha 不继承 Card 材质透明度，只有抗锯齿边缘保留字形自身覆盖率。缓冲都只在重绘时分配并在函数返回后释放，不是常驻缓存；隐藏 Card 不产生该成本。Shell 图标在材质与内容合成完成后按自身预乘 Alpha 直接叠加。

## 字体彩边根因与策略

ClearType 为每个字形边缘分别计算红、绿、蓝子像素覆盖率。该结果适合直接显示在确定的不透明背景上；写入分层 DIB 后再由 `UpdateLayeredWindow` 与未知墙纸做第二次 Alpha 合成，会把覆盖率暴露成橙色和青色散边。这不是图像锐化，也不能通过降低字体颜色解决。

最初只把 GDI 改成 `ANTIALIASED_QUALITY` 仍不充分：字形先画入近白材质 RGB，最终阶段再用颜色深浅反推内容覆盖率。小字号的半覆盖像素已经与近白底混色，反推时会被当成无内容或错误地抬成不透明，结果是硬边、缺笔和按钮发白。当前实现先在黑底 mask 上用白色绘制灰阶覆盖，再以目标文字颜色生成独立预乘内容像素；材质 Alpha、字形 Alpha 和圆角覆盖率最后一次性按 SourceOver 合成，不再从颜色猜 Alpha。

处理边界：

- Card 标题保持 14 px `Segoe UI Variable Text / FW_SEMIBOLD`，左侧起点由 14 DIP 调整为 18 DIP；文件名、Todo 操作文字/正文/元数据、空状态、添加入口和 Fluent glyph 与标题一起通过独立 mask 保留每像素灰阶覆盖，文字不随任何外观的材质 Alpha 变淡。
- 浅色和水晶外观的 Todo 操作层级使用稳定深色，不根据墙纸亮度改变：主操作最深，归档/完成项/时间等次级信息略浅，但都保持可读对比度。
- Todo 正文无论是否包含 Emoji 都统一使用 13 DIP `Segoe UI Emoji` 的 DirectWrite/Direct2D 路径，消除纯文本 GDI 与 Emoji DirectWrite 在视觉字号、行高和灰阶覆盖上的差异；用户偏好的较小 Emoji 视觉尺度因此也成为纯文本待办的统一尺度。创建时间使用同一路径的 10 DIP 单行布局。DCRenderTarget 显式设置 `D2D1_TEXT_ANTIALIAS_MODE_GRAYSCALE`，禁止普通字形部分输出 RGB 子像素覆盖，同时保留彩色 Emoji 图层。
- 设置窗口、Tooltip 和系统菜单是不透明目标。Todo/File/设置编辑器统一使用 `WindowsTextInput` 的 DirectWrite `ENABLE_COLOR_FONT + GRAYSCALE` 路径，普通文字、彩色 Emoji、选区、组合串和光标共享同一布局，因此编辑态不会退化为单色 Emoji，也不会出现 GDI 测量与 DirectWrite 绘制的位置差异。
- 32 位 DIB 回归测试按实际 14 px 小字号绘制纯中文，要求抗锯齿像素存在且任意像素 RGB 最大通道差不超过 1；预乘合成测试要求半覆盖内容保留中间 Alpha 且实体字形不再受底板 Alpha 削弱。Emoji 测试另行要求彩色像素存在，因此不会误把 Emoji 色彩当成字体彩边。

## 配置迁移

schema 25 处理 `appearance.preset == "transparent-white"` 且 `opacity` 与上一代内置预设值 0.36 精确相等的 Card；schema 26 再处理真实配置中发现的第一代内置值 0.62，两者都改为 0.32。设置界面没有自由透明度编辑器，因此这两个精确值属于历史预设而不是当前 UI 可表达的主动选择。0.5 等其他 Alpha、其他预设和未知字段全部保留；备份和原子写入规则不变。

## 编辑器材质与生命周期

Todo 添加使用一个单 HWND 的 `DestoWindowsTextInput` Popup。窗口内部持有文本、选区、撤销、剪贴板和 TSF `ITextStoreACP` 状态；Windows 输入法直接修改该文本存储，候选窗口位置来自同一 DirectWrite 布局计算的光标矩形。背景、1 DIP 内描边、占位符、普通文字、彩色 Emoji、选区、组合串下划线和光标都由这个窗口一次绘制，不再存在 Popup 宿主、子 Edit 或 Card 父窗口补画。

`transparent-white` 使用 `WS_EX_LAYERED + UpdateLayeredWindow` 的逐像素预乘 Alpha；透明背景区域保留最小命中 Alpha，圆角外区域由窗口 Region 裁掉。旧的 `LWA_COLORKEY` 路径已经删除，因此任何与色键相同的文字或 Emoji 像素都不会被误删。布局固定单行并垂直居中；编辑期间 Card 不再绘制底层“+ 添加待办”，视觉和命中都只有一个状态。

水晶外观的置顶、收缩、网格/列表、Todo 日期/归档/剩余、复选框及添加符号使用比普通浅色外观更深的独立内容色；这些颜色以完整内容 Alpha 合成，不继承 0.32 的 Card 底板透明度。

设置页的归档搜索、归档补录和 Card 重命名复用同一个深模块，只以 Child 窗口方式嵌入设置页。调用方提供矩形、颜色、圆角、字体、占位符和通知 ID，不读取文本后重复绘制。Card 标题开始编辑时光标位于文本末尾；TSF 组合串、最终选区和可见光标始终来自模块内同一个状态。项目中不再创建任何输入用途的原生 Edit。

Todo 限高先决定可见条目，再进入渲染。`todoEntryRect()` 为限高外条目返回的哨兵矩形不能参与后续绘制；渲染循环在创建复选框、文字、日期和时间之前统一过滤空矩形、标题区上方矩形及 `visibleBottom` 之外的矩形。否则零宽矩形仍会被 `todoCheckboxRect()` 扩成底边圆形，圆形上半部被 Card 裁切后表现为限高区域底部的孤立圆框。

`todoEditorSurface` 是编辑窗口到 Card Surface 的显式归属。Card 折叠、进入移动/缩放、删除、全局隐藏、桌面生命周期不可见或内容偏好引起几何变化时，统一按归属取消并销毁输入窗口，不提交半成品；Enter 和正常失焦仍按既有规则提交。

## 验收

- 自动：`WindowsTextInputTests` 验证单 HWND、无 Edit 子窗口、中文连续输入、UTF-16 Emoji、选区、撤销、提交/取消、透明 Popup 非空像素和彩色像素；桌面/设置宿主测试验证四类调用均接入同一窗口、折叠销毁、标题末尾光标、Todo 限高、材质与圆角回归；配置测试继续验证设置入口 0.32、schema 24/25/26 迁移及自定义 Alpha 保留。
- 真实桌面像素：问题截图的外观 5 标题存在 114 个实体字形像素但灰阶过渡像素为 0；修复后本机最终桌面合成截图检测到 157 个实体像素、23 个灰阶过渡像素、0 个橙青彩色边缘像素。
- 人工：分别在明亮、深色和高频细节墙纸上查看水晶 Card；底板应明显透出桌面，图标格填充可辨、亮线比填充更清楚，标题和文件名无橙青色边缘，彩色 Emoji 颜色正常。
