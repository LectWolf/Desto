## 证据等级

- **代码事实**：可从当前源码直接读出，标注实现文件。
- **自动验证**：已有测试或门禁命令在当前构建中通过。
- **文档声明**：现有长期文档的意图，尚未等同于运行时事实。
- **人工待验**：需要真实桌面、显示器、DPI、Explorer 或窗口组合才能确认。
- **用户决策**：存在互斥的产品语义，代理不应猜测。
