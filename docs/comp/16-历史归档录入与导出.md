# 历史归档录入与导出

## 历史录入

归档页右上角“添加”打开自绘浮层。浮层在多个 Todo Card 间循环选择，文本使用统一的 `WindowsTextInput` 自绘窗口；模块通过 TSF 保留 Windows 中文输入法，并自行处理 Emoji、撤销、剪贴板、圆角底板、选区和光标，不创建隐藏 `EDIT`。归档日期沿用页面当前选择，不新增系统日期组件。

应用层生成 Card 内唯一的 `history` ID，使用 `AddHistoricalArchivedTodoItem` 一次写入标题、历史自然日中午的时间戳、计划日期、`completed=true` 和 `archived=true`。命令先验证 Card 类型、ID、时间和日期，再整体替换 Todo 列表。schema 27 的 TodoItem 已具备全部字段，因此不升级配置格式。

## TXT 导出

“导出”浮层提供当天、7 天和 30 天三个跨度，当前归档日期为包含式结束日。确认后才打开 Windows 保存文件对话框；文件内容为 UTF-8 BOM 和 CRLF，首行给出跨度，随后按 Todo Card 分组输出日期与标题。读取跨度内显式归档及按完成日期自动进入归档的兼容项目，不改变归档状态、排序或配置。

取消对话框不写文件。目标无法打开或写入不完整时返回失败并记录 `settings.archive_export_failed`。导出路径与跨度不持久化，不增加常驻资源。
