# 性能、测试与发布

## 当前自动测试

当前 CTest 注册 23 项：domain、workspace layout、display topology、Windows single instance/startup integration/desktop host/trigger/settings/text input/icon font/file drag-drop/Shell catalog/directory change、fault injection、application runtime/transfer/ordering/lifecycle、storage/import、CardView、CardContentLayout 和 placement interaction。旧构建目录可能残留已删除目标的 exe，不能当作当前清单。

推荐命令：

```powershell
cmake --build build --config Debug
ctest --test-dir build -C Debug --output-on-failure
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
git diff --check
```

2026-08-20 本轮 Debug 与 Release 全量构建通过，两个配置的 CTest 最终均为 22/22。新增回归覆盖跨日期归档搜索、Todo 跨行 100 次零完整 Render/Commit、Card 月历最小 380 DIP、日期入口双击不打开且 500 ms 长按打开、归档月历显示时搜索 HWND 隐藏、Hook 线程与 UI 线程隔离，以及 Popup 的 20 次光标请求和一次输入合并为一次 paint、同尺寸期间只创建一次 backing store/RenderTarget。既有层级、拖放、存储和稳定性测试全部通过。

2026-08-21 Windows 10 图标兼容修订后，Debug/Release 全量均为当时构建的 23/23。新增测试强制模拟 `Segoe Fluent Icons` 缺失，断言选择 Windows 10 原生 `Segoe MDL2 Assets`，并通过 `GetGlyphIndicesW` 验证重命名、更多、删除和折叠关键码位不是缺字；虚构字体必须判定为不存在，防止字体枚举返回值误判。当前工作树在 2026-08-23 的 Release 全量为 24/24。

Release 首次全量运行曾在拖放预览取消断言中出现一次定时器时序红灯：产品使用 90 ms 延迟吸收 OLE `DragLeave/DragEnter` 抖动，测试只休眠 100 ms 后读取窗口，冷构建负载下余量不足。测试现改为持续泵送窗口消息，直到原矩形恢复或 500 ms 超时；没有放宽坐标断言。该阶段修订后 Release 定向连续 10/10、当时的 Release/Debug 全量 21/21 通过；当前清单和结果见上方 22/22 记录。

## 性能基线

目标：Empty private working set ≤30 MB、Typical ≤50 MB、稳定空闲 CPU 约 0%、冷启动 ≤500 ms、同步显隐提交目标 ≤16 ms。基准必须记录 Windows 版本、DPI、显示器、Card 数量、项目数和图标像素。

已记录正式宿主 Release 场景：

| 场景 | 启动 | 显隐 P95 | 私有 MB | 线程 | 空闲 CPU |
|---|---:|---:|---:|---:|---:|
| Empty | 19.66–29.24 ms | 0.05–0.37 ms | 2.07–2.10 | 7 | 0% |
| Typical | 88.38–133.99 ms | 6.22–9.93 ms | 5.06–5.16 | 7 | 0% |

schema 23 阶段的单次 Release smoke：Empty 为 30.13 ms / 0.13 ms / 2,174,976 bytes / 7 threads / 0%；Typical 为 158.42 ms / 13.92 ms / 5,292,032 bytes / 7 threads / 0%。两项门禁通过；该历史单次结果不替代 schema 24 的本轮重测。

schema 24 本轮 Release 实测：Empty 为 25.87 ms / 0.077 ms / 2,138,112 bytes / 7 threads / 0%；Typical 为 153.44 ms / 13.27 ms / 5,300,224 bytes / 7 threads / 0%。两项均输出 `passed=1`；Typical 的 13.27 ms 显隐 P95 仍低于 16 ms 目标。环境为 Windows 11 Pro 10.0.26200、Intel Core i7-11800H、16 logical processors，测量时间 2026-08-18。

2026-08-19 Windows 交互与内容兼容修订后再次执行 Release 门禁：Empty 为 24.3736 ms / 0.1048 ms / 2,162,688 bytes / 7 threads / 0%；Typical 为 116.361 ms / 14.8003 ms / 5,320,704 bytes / 7 threads / 0%。两项均为 `passed=1`，Typical 显隐 P95 仍低于 16 ms。该次变更只在目录枚举时按项目查询隐藏属性、Todo 绘制时按需创建 Emoji 字体、右键菜单显示期间临时持有 Shell COM 接口；没有新增常驻线程或空闲唤醒。

2026-08-19 归档、Folder MOVE、彩色 Emoji、菜单策略和启动注册修订后的 Release 门禁：Empty 为 20.8039 ms / 0.0649 ms / 2,277,376 bytes / 7 threads / 0%；Typical 为 94.4816 ms / 5.1364 ms / 5,451,776 bytes / 7 threads / 0%。两项均为 `passed=1`。DirectWrite/Direct2D 仅在 Todo 实际包含 Emoji 时按需初始化；固定 Empty/Typical 基准没有 Emoji，因此这组数字证明默认路径无新增常驻线程，但不代表首次彩色 Emoji 绘制的按需成本。

2026-08-19 schema 25 水晶材质与分层字体最终 Release：Empty 为 19.1477 ms / 0.1879 ms / 2,195,456 bytes / 7 threads / 0%；Typical 为 131.095 ms / 8.3312 ms / 5,390,336 bytes / 7 threads / 0%。两项均为 `passed=1`，Typical 显隐 P95 低于 16 ms。水晶图标框的 1 byte/pixel coverage 只在对应 Card 重绘期间存在，固定默认场景没有新增线程或空闲唤醒。

2026-08-20 最终 Release：Empty 为 15.7921 ms / 0.1026 ms / 2,260,992 bytes / 7 threads / 0%；Typical 为 158.319 ms / 8.0367 ms / 5,554,176 bytes / 7 threads / 0%，两项均为 `passed=1`。拆分探针确认文件 Card 路径正常，异常来自纯 Todo 文本误入彩色 Emoji Direct2D 路径；修正实际 Emoji 判定后，Typical 从诊断样本的 57,470,976 bytes / 19 threads 回到 5,554,176 bytes / 7 threads。独立鼠标 Hook 线程不属于该宿主门禁；它阻塞在消息队列且没有空闲轮询，线程隔离由 Windows trigger 测试覆盖。

同日长按日期、月历内容层和输入合帧修复后复测：Empty 为 18.0746 ms / 0.1142 ms / 2,269,184 bytes / 7 threads / 0%；Typical 为 111.09 ms / 7.0531 ms / 5,537,792 bytes / 7 threads / 0%，两项 `passed=1`。Empty 首次采样受瞬时调度影响记录到 1.53899% CPU，连续两次复测均为 0%；Popup 合帧没有增加线程或空闲唤醒。

## 安装与发布

- Inno Setup 6，x64、按用户安装、静态 MSVC CRT；程序和数据生命周期分离。
- 升级保留 settings/Card；schema 23 迁移会明确删除旧扩展 state；旧安装包拒绝覆盖新版本；卸载默认保留数据并提供删除数据选项；始终清理计划任务和 Run 回退值。
- 发布脚本只生成宿主 installer、release-manifest、SHA256SUMS、BUILDINFO 和第三方声明；不再生成扩展 zip。GitHub Actions 固定到 commit，Release 先草稿。
- VerifyRelease 拒绝版本越界、缺失或篡改资产；正式发布前必须有根许可证、公开 GitHub 仓库和 Authenticode 证书。
- 当前安装/升级/降级拒绝/卸载保留数据已在本机隔离目录验证；安装器和 exe 未签名，SmartScreen 风险仍在。

## 人工验收最小矩阵

1. 两台不同 DPI 显示器上拖动 Card，观察设置窗口层级和 Placement 恢复。
2. Large 4→5 列、Small、List、Grid 往返，记录 DIP 与实际像素宽度，确认用户期待的外框策略。
3. 多个最大化/普通窗口按已知顺序执行任务栏双击、预览、新窗口、再次双击，记录恢复顺序。
4. Windows 深浅主题切换后检查 Card、设置和托盘原生菜单。
5. schema 22 含旧扩展 Card 的真实配置升级到 schema 23，确认内置 Card 可启动且旧扩展 Placement 不残留。
6. 分别双击任务栏空白、应用按钮和任务视图/搜索等控件；只有明确空白区域应触发配置动作。
7. Mapping Folder 中准备普通文件、启动时已隐藏文件、运行中改为隐藏的文件；Grid/List 都只能显示普通文件。
8. Todo 输入普通文本、单个 Emoji、带 VS16 的符号和 ZWJ 组合，重启后确认文本、换行和行高不丢失。
9. 在 Application/Mapping 的 Grid 与 List 中右键真实项目：Win11 默认应先出现紧凑核心命令并可进入“显示更多选项”，关闭 Win11 菜单后应直接出现完整菜单；背景不应弹出文件菜单，托盘悬浮文字应为 `Desto`。
10. Folder Mapping 开启/关闭来源修改分别拖入文件，核对 MOVE/NONE、同名改名和来源目录；归档页启动时显示昨天，切换今天/前天后不混入其他日期。
11. 开启开机启动后检查任务计划程序中的 `Desto` 登录任务无 Delay；若系统策略拒绝创建，诊断应记录 Run 回退，开机启动仍可用。
12. 全新隔离配置启动后确认桌面没有自动 Card，设置页 Card 列表为空，数据根没有 `mapping-preview`；随后手动添加三种 Card。
13. 开启/关闭“显示文件名”分别检查紧凑与经典右键；确认文件和文件夹的 Open/Cut/Copy/Delete/Properties 行为由 Explorer Shell 执行，Desto 不显示文件项 Rename。
14. 点击归档日期标签选择同月/跨月历史日期，验证未来日期禁用、Escape/外部点击关闭；在明暗墙纸上切换水晶透明预设，确认桌面明显透出、文字可读、图标边缘不发白。
