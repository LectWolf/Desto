# 卡片类型行为

## Application Card

### 来源与归属

内容目录位于 Desto storage root 下，Card 只保存相对路径。把 Explorer 文件拖入 Application Card 是所有权转移，要求 MOVE；目标冲突由 `DirectoryImportPlanner` 生成不覆盖的目标名。跨卡移动先执行可回滚文件事务，再在同一批中准备源/目标 CardView，任一后续步骤失败必须回滚磁盘和内存布局。

### 文件项字段

每项包含 id、displayName、sourcePath、快捷方式 resolvedTargetPath、AppUserModelId、fileSize、itemType、modifiedTime、state 和一份图标。状态：Ready、Missing、UnresolvedShortcut、IconUnavailable。

- `.lnk` 显示名去掉扩展名；其他项目显示原文件名。
- 快捷方式先读 ShellLink target 和 AppUserModelId；商店应用从 `shell:AppsFolder\<AUMID>` 取图标。
- 无法解析快捷方式不会伪装成普通文件；无法取图标但项目存在时标记 IconUnavailable。
- 双击 Ready 项通过 `ShellExecuteW(open)` 启动；Missing/UnresolvedShortcut 拒绝启动。
- Application/Mapping 的 Grid 与 List 共用项目命中测试。右键实际文件项时通过绝对 PIDL 绑定父 `IShellFolder`，请求 `IContextMenu` 并执行 Explorer 原生命令；菜单打开期间把 `WM_INITMENUPOPUP`、`WM_DRAWITEM`、`WM_MEASUREITEM` 和 `WM_MENUCHAR` 转发给 `IContextMenu2/3`。文件项重命名入口不在 Desto 中提供；文件夹的 Open 仍交给资源管理器。卡片背景不打开文件菜单。

### 排序与位置

- Custom 保存稀疏槽位；路径键大小写不敏感，槽位唯一。
- Name、Size、ItemType、ModifiedDate 只生成临时投影，不覆盖 Custom。
- 新文件优先填补第一个空槽；Fixed 可传最大行数，容量不足必须明确失败。
- Application 槽位 JSON 只保存文件名，不保存绝对 storage root。

### 列表与网格

schema 22 为 Application 增加 `presentationMode`。Grid 使用四档槽位；List 强制单列、每项 42 DIP 高、图标 26 DIP，使用独立宽度分支。Custom 模式进入 List 时不会直接复用稀疏 Grid 的 `column/row`：宿主先按原槽位 `(row,column)` 稳定排序，再临时投影为 `(column=0,row=0..N-1)`；没有自定义槽位的新项目按当前项目顺序追加。该展平只影响画面与命中，切回 Grid 后恢复原稀疏槽位。

切换 presentation 不改变来源、排序数据或图标快照，不调用目录枚举/项目刷新回调。切换会重新测量当前 Card，提交新 surface rect 和 Placement，再按 8 DIP 间距移动完整下方堆叠链。设置页只控制标题栏切换入口的显示/隐藏；真正切换 Grid/List 仍由 Card 标题栏入口执行。

Grid 与 List 的每个文件项都支持右键，命中后打开该路径在 Explorer 中的原生 Shell 菜单；背景、行间隙和不可见滚动项不触发。List 即使由 Custom 稀疏槽位展平，也以画面中的连续行命中同一个原始文件项。名称编辑器与绘制共用 `itemLabelRect`：Grid 覆盖图标下方标签，List 覆盖图标右侧标签；文件默认选中 stem，目录全选，快捷方式隐藏的 `.lnk` 在提交时保留。成功事务同步替换 Application 文件名 Placement 或 Mapping 绝对路径 Placement；References 额外替换稳定 reference 的 path，失败反向恢复文件和内存视图。

### 删除

所有 Card 都需要二次确认。Application 删除预览明确为“把管理文件退回桌面”；存在同名时改名，不覆盖桌面原项目。返回事务失败时不提交 Card 删除。

## Mapping Card

### Folder 模式

- sourceRoot 为绝对目录且同一来源只能被一个 Mapping Card 占用。
- `allowsSourceMutation=true` 时可把外部文件拖入来源目录；关闭时 Card 是只读投影。
- 目录监听使用 `ReadDirectoryChangesW`；60 ms 合并窗口内保留相对路径并增量更新。
- 首次目录枚举和增量路径刷新都读取 Win32 文件属性并过滤 `FILE_ATTRIBUTE_HIDDEN`。已显示项目后来变为隐藏时，增量刷新先移除旧投影且不重新加入。
- 单卡一次超过 512 路径、缓冲溢出或路径无法安全归入根目录时回退全量枚举。
- 外部移动/删除实时反映；删除 Card 绝不移动源目录内容。

### References 模式

- 保存显式引用集合，加入时不移动文件。
- 原文件消失后保留引用并以 Missing 展示；失效是可观察状态，不静默删除。
- 空引用集合仍可保持 References 来源形态；切换来源模式会清除旧来源和旧槽位。

### 拖放语义

- 从同一 Mapping Card 内部重排可接受 MOVE。
- References 根内容的外部或其他 Card 拖入接受 COPY，只增加绝对路径引用；根文件拖出只允许 COPY。根引用文件夹只提供 Desto 内部拖放格式，不提供 Explorer 可复制的 `CF_HDROP`，在 Desto 外释放时仅显示自绘移除映射确认；卡片内重排不会误触发确认。进入引用文件夹后拖入、拖出直接操作当前源目录中的真实文件，拖入通过文件移动事务提交；取消移除确认或拖动失败都会清理拖动状态，不会使后续操作失效。锁定 Card 时拖入、拖出、重排和右键修改均禁用。
- Folder 已有 sourceRoot 且 `allowsSourceMutation=true` 时接受 MOVE，使用 DirectoryImportPlanner 规划冲突名并由 FileMoveTransaction 执行；任一失败回滚整批。
- Folder 未设置 sourceRoot 时，单个目录 Drop 以 COPY 选择来源，避免 Explorer 把未移动目录当成 MOVE；已有 sourceRoot（即使目录为空）且 `allowsSourceMutation=true` 时普通文件/文件夹 Drop 返回 MOVE；`allowsSourceMutation=false` 时普通文件 Drop 返回 NONE。
- 成功移动后立即枚举 sourceRoot、按绝对目标路径重建自定义槽位并保存；来源 Card 通过 OLE Performed DropEffect 或目录监听收敛。
- MappingCard 向外部目标拖出后，源卡片在 OLE 手势结束时立即刷新，不依赖目录监听的到达顺序，也不因目标回报 NONE 而保留旧项目。
- Mapping 自定义槽位以绝对路径识别，避免同名不同目录被合并。

## Todo Card

### 可见集合

- 默认聚焦今天；今天视图包含逾期项和当天项，逾期按日期稳定排序。
- `todoRemainingOnly` 可只显示未完成项；完成不会自动归档。
- 日期切换支持今天/明天等偏移；未指定 scheduledDate 的项目按今天处理。
- 今天/明天不展示已归档项；其他日期同时展示该日未归档项和归档项，归档项用「归档」标签且不加删除线。
- 自动归档判断依赖完成日期和当前日期；显式 archive 字段也可归档。

### 几何与操作

- 视图按钮：左 `10..78 DIP`、顶部 `44..76 DIP`。
- 视图按钮短按切换今天/明天；持续按住 500 ms 且指针仍在按钮内才打开日期面板，触发长按后抬起不会再切日期，双击无特殊日期行为。
- 归档按钮：卡片右侧预留区域，顶部 `44..76 DIP`。
- 剩余项展示：右 `76 DIP` 区域，顶部 `44..76 DIP`；有稳定背景但不接受点击。
- 添加按钮：左右 inset 10 DIP，顶部 80 DIP，高 44 DIP。
- checkbox 18 DIP，距行左侧 8 DIP；热点会额外放大以便点击。
- 系统拖动阈值使用 `SM_CXDRAG/SM_CYDRAG`；行拖动后发出 ReorderTodoItems。
- 编辑器是单 HWND 的 `WindowsTextInput` 自绘窗口，按主题绘制文字、背景、圆角与边框，通过 TSF 接收中文输入并由 DirectWrite 统一排版普通文本和 Emoji；Enter 提交、取消/失焦按宿主策略收尾，不创建原生 EDIT 子窗口。
- Popup 编辑器同尺寸重绘复用一套 DIB、Memory DC 和 D2D DC RenderTarget；同一消息周期内的文字、选区、组合输入和光标请求合并为一次分层窗口提交，文字/选区变化重置 530 ms 光标周期，尺寸变化和销毁释放缓存。
- 普通 Todo 行悬停在行切换时绘制浅底并提交一次完整 Card；同一行内移动不重绘。按钮、按下、复选框和拖动反馈仍重绘。
- Card 内月历打开后可见高度至少 380 DIP，面板从 80 DIP 开始；打开时取消未提交的添加输入，并隐藏条目、日期标签底和「剩余」底，避免透出日历。面板用浅霜填充，再画贡献格、选中态、今天描边和文字。
- 待办标题仍以 UTF-8 持久化；Win32 UTF-16 编辑文本使用严格代理对校验转换为 UTF-8。绘制和换行测量检测 Emoji 范围、VS16 与 ZWJ，含 Emoji 时按需使用 DirectWrite/Direct2D `ENABLE_COLOR_FONT` 绘制 Windows 彩色 `Segoe UI Emoji`，普通文本继续使用 GDI `Segoe UI Variable Text`。

### 归档页

设置页默认展示设置时区中的今天，左右按钮按自然日切换且不越过今天；日期标签打开 336×284 px 自绘浮层，标题区 46 px、星期区 28 px、日期区为 7 列×6 行且单元格 48×34 px。星期从周一开始；非本月日期弱化、未来日期禁用、今天描边、选中日期使用强调色。月份前后导航不越过当前月，选择后换算为相对今天的日差、重置归档列表偏移并关闭；Escape、外部点击、切页关闭。日历打开期间隐藏作为子 HWND 的搜索输入，关闭后立即恢复，避免子窗口覆盖父窗口绘制的日期面板。搜索非空时遍历所有日期，清空后恢复选中日期过滤。完成时间是归档日期来源，缺失时回退创建时间。无内容面板高 88 px。导出弹层包含开始/结束两个日期框和同层自绘 6×7 月历，默认范围为选中日及之前 6 天，范围始终有序且包含两端。单项恢复、永久删除和 Card 内显式归档均按稳定 Card/Item ID 回调；永久删除前进入统一确认面板，回调同步整张 Card 后不得复用旧索引二次删除。

## 共同行为

- 标题栏右侧 collapse 为 36 DIP 方形、距边 6 DIP；pin 与 collapse 间距 2 DIP；文件展示切换入口继续向左排列。入口可按实例隐藏，隐藏后不占标题空间且原区域恢复为拖动标题栏。
- 标题区除控件命中区外可原生拖动；窗口边缘返回内容命中，不提供 resize cursor。
- tooltip 在 600 ms 后显示 displayName，并附加 missing/shortcut unavailable 诊断行。
- 收缩/展开、置顶、标题显示、内容密度、最大行数均为实例字段。
