# 总览与运行时

## 产品边界

Desto 是 Windows 常驻桌面整理工具。核心对象是 Card，Card 的位置和尺寸属于 WorkspaceLayout 的 Placement；一个 Card 可在多个指定显示器出现，也可以显式使用 AllDisplays。目标是低内存、低空闲 CPU、快速同步显隐和稳定多屏恢复。

## 构建与进程

- C++20，CMake 3.25+；MSVC 使用 UTF-8 编译选项和静态 CRT（`CMakeLists.txt`）。
- 正式宿主：`apps/Desto.exe`，Win32 GUI 子系统。
- 主模块：`src/domain`、`src/application`、`src/presentation`、`src/platform/windows`、`src/storage`。
- 渲染：每个 Card 一个 `WS_EX_LAYERED` 分层窗口；内容先画到 GDI DIB，再通过 `UpdateLayeredWindow` 提交预乘 Alpha 像素。默认不引入 Qt、WinUI、WebView。
- 正式宿主是 Win32 分层窗口；DirectComposition 只留在历史 ADR 中比较。
- 进程内还有隐藏的生命周期窗口，接收 `TaskbarCreated`、锁屏/解锁和电源恢复消息。

## 主要状态流

```text
Win32 消息/COM 拖放/系统事件
  -> ApplicationCommand
  -> ApplicationRuntime::execute
  -> Card/Workspace 状态变更
  -> deferred 或 immediate 持久化
  -> immutable CardView / PlacementProjection
  -> WindowsDesktopHost 批量重绘和显隐
```

`ApplicationRuntime` 明确声明“命令由应用循环串行化，本类型不保证线程安全”。宿主保持 projection 和 surface 的临时状态，不把 HWND、HMONITOR 或 RECT 写进领域对象。

## 关键事件和计时器

| 机制 | 实现值 | 作用 |
|---|---:|---|
| 文件项 tooltip | 600 ms | 鼠标停留后显示名称/缺失状态 |
| 拖放预览复位 | 90 ms | 预览槽位短暂离开后的复位 |
| 自适应边缘扩展初始等待 | 200 ms | 拖到卡片边缘后扩列/扩行 |
| 向左扩展阻尼 | 每次 +300 ms，无上限 | 仅 Right 锚点保持右边缘、向左扩张时防止指针持续停留在扩展区 |
| Shell 重新绑定重试 | 250 ms | Explorer/桌面 owner 暂时不可用 |
| 显示拓扑查询防抖 | 构造时传入 | `DisplayTopologyMonitor` 只合并连接/断开等重复查询，不决定交互式 DPI 切换 |

## Surface 临时状态

每个 surface 保存窗口句柄、DIB、projection、display snapshot、CardView、DPI、尺寸、悬停/按下状态、tooltip、拖放状态、拖动起点、滚动行偏移和待办拖动状态。滚动偏移、hover 和 pressed 不写入 JSON；没有扩展数字字体、金额背景缓存或动画 deadline。

## 资源停止规则

- Card 隐藏时停止不必要的 Mapping 目录监视；重新显示前做一次全量对账再恢复增量监视。
- 关闭入口只改变实例偏好，能力仍存在；专属工作只有在实际功能关闭时才应停止。
- Shell 图标缓存默认最多 256 项、8 MiB，按最近使用淘汰；隐藏状态清空 LRU 引用。
- 无持续动画循环；已撤销的数字滚动和时间驱动 Card 不再设置 timer 或 deadline。

## 已知运行时边界

- 当前没有扩展 DLL 加载或第三方代码执行面；schema 22 的旧扩展数据只参与一次性迁移删除。
- 真实 Explorer 崩溃、物理热插拔、锁屏/休眠和虚拟桌面仍需真实桌面验收，自动测试只模拟部分消息。
- 全局设置只应作为默认值；实例已明确的字段由实例覆盖保留。
