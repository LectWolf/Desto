# 卡片模型与配置

## 通用 Card 字段

`Card`（`src/domain/Card.h`）拥有：

| 字段 | 默认值 | 规则 |
|---|---|---|
| `id` | 无 | 非空，稳定字符串；空值构造失败 |
| `name` | 空 | 1–192 UTF-8 字节；空名称由 Presentation 显示类型名 |
| `type` | Todo 枚举默认 | Application / Mapping / Todo |
| `visible` | `true` | 是否参加当前 Workspace 正常 projection |
| `expanded` | `true` | 收缩只影响内容高度，不删除内容 |
| `chrome` | 见下 | 实例级入口和置顶行为 |
| `appearance` | system/1.0/16 | 预设、背景不透明度、圆角 |
| `content` | Large/Adaptive/widthSpan=4 | 图标密度、列宽和最大行数 |

### Chrome

`showTitle=true`、`showCollapseControl=true`、`showCloseControl=false`、`showPinControl=false`、`showPresentationControl=true`、`pinOnTop=false`。能力、入口和表现分离：隐藏展示切换按钮不会修改 Grid/List 状态；隐藏关闭/置顶按钮不会删除能力；`pinOnTop` 只有在显示 pin 能力时才有可见入口。

### Appearance

`preset` 默认为 `system`；`opacity` 范围 `[0,1]`；`cornerRadius` 范围 `[0,128]` DIP。可见预设为 system、mica-dark、mica-white、brand、transparent-white；最后一项由设置入口写入当前水晶底板 Alpha（0.20）；渲染器将底板、图标框填充、图标框线框、Card 外轮廓、内容可读 Alpha 和 Shell 图标预乘 Alpha 分开处理。设置页全局圆角预设为 0、12、24、32 DIP，运行时会批量更新所有 Card 的实例字段；这是用户确认的显式批量命令。

### Content

| 字段 | 默认值/范围 | 作用 |
|---|---|---|
| `itemSize` | Large | Small / Medium / Large / ExtraLarge |
| `showItemNames` | false | 文件/映射项标题换行到图标下方 |
| `sizeMode` | Adaptive | Adaptive 或 Fixed |
| `widthSpan` | 4，1–64（且不低于密度最小值） | Card 外宽轨道跨度；当前文件卡片也用于列数约束 |
| `fixedColumns` | 4，1–64 | 兼容字段/固定网格投影列数；设置动作会由 widthSpan 重新投影 |
| `fixedRows` | 3，1–64 | Fixed 模式容量行数 |
| `maximumVisibleRows` | null 或 1–64 | 实例显式上限；null 表示不额外限行，但仍服从工作区/下方堆叠链自动容量，任一上限造成截断后启用滚动 |

Application Fixed 模式会检查每个自定义槽位 `column < ProjectCardColumns(widthSpan,itemSize)` 且 `row < fixedRows`；越界命令拒绝。Mapping 的绝对路径槽位单独校验。

## 具体类型

### ApplicationCard

- `relativeStoragePath`：相对 storage root、非空、非绝对；代表 Desto 管理的目录。
- `sortMode`：Custom / Name / Size / ItemType / ModifiedDate。
- `itemPlacements`：文件名 + 稀疏 `(column,row)`；文件名必须是单一文件名、相对、大小写不敏感唯一，槽位不得重复。
- `presentationMode`：Grid / List。
- 删除效果固定为 `ReturnManagedItemsToDesktop`，需要二次确认。

### MappingCard

- `mode`：Folder、References；`Empty` 是领域枚举但 `setMode(Empty)` 拒绝，清空来源由 `clearSource()` 完成。
- Folder 来源要求绝对路径，切换时清除引用和槽位；默认允许反向修改源目录。
- References 每项需要非空 id + 绝对路径；id 和规范化路径均唯一；不移动外部文件。
- Mapping 槽位保存绝对路径、列、行，来源切换会清除槽位。
- `presentationMode`：Grid / List；`sortMode` 与 Application 相同。
- 删除效果固定为 `RemoveCardOnly`，不会删除外部文件。

### TodoCard

- item：非空唯一 id；标题有可见字符且最多 512 UTF-8 字节；created/completed 时间戳非负。
- 未完成项的 `completedAt` 必须为 0；scheduledDate 必须是合法公历日期。
- `completed` 不等于 `archived`；可单项或批量归档、恢复、删除。
- `showCreatedTime` 控制创建时间元数据；日期按实例/系统时区显示“今天、明天、逾期”等。

## 命令与错误

`ApplicationRuntime` 支持创建、重命名、显隐、展开、Chrome、Appearance、Content、Placement、拓扑、Todo 增删改排/归档、Mapping 来源/布局/模式、Application 布局和三段式删除（Request / Cancel / Commit）。错误枚举包括重复 Card、找不到 Card/Placement、删除 token 不匹配、映射来源占用、Todo item 不存在/重复和非法命令。

每次结果包含 `Applied / NoChange / Rejected`、revision、变更集合、诊断文本和持久化紧急度（None / Deferred / Immediate）。

## 配置解析优先级

```text
application default -> card-type default -> card instance override
```

实例明确字段不应被全局默认覆盖；未知 JSON 字段读取后通过原始节点保留并在保存时合并回去。当前 schema 为 24；旧扩展字段是迁移删除的明确例外。
