## 数据流核验点

1. 设置页回调应只产生 ApplicationCommand 或明确的应用级副作用；不要绕过 Runtime 直接改 Card。
2. WindowsDesktopHost 应消费 CardView/Projection，不读取 Card 子类或 JSON。
3. 文件事务完成后才更新 Card 归属和窗口画面；回滚时要同时恢复源/目标视图。
4. Mapping 目录监视只在可见/有来源时运行，来源切换时替换 watches。
5. schema 22 的扩展 Card 必须在 JSON 迁移阶段连同 Placement 和排序引用一起删除，不能进入 Runtime。
6. 所有配置写入最终经过 JsonConfigStore 原子替换；测试中不能只验证内存状态。
