# Desto Delivery Roadmap

本路线只保留尚需验收的交付事项。原 1-55 已完成能力不再作为当前任务重复列出；其长期行为分别保存在产品、架构、功能文档和 `docs/comp` 中。

## Progress Rules

- 所有阶段更新和最终回复使用 `（N/6）事项名`。
- 一项以可完整验收为粒度，不按回复次数或提交数量递增。
- 新增范围插入最早依赖位置后重新编号。

## 01. v2 重构基础与配置恢复协议 [x]

固化 Desto v2 的模块边界和自有 UI 组件接口；删除彩色 Emoji 渲染能力；输入框、Card、设置页和恢复界面统一使用 GDI DIB 自绘；JSON 继续作为主配置格式，但引入校验、两代以上轮换备份、损坏主配置的用户确认恢复和 v1 schema 迁移入口。

退出条件：ADR、模块依赖图和迁移协议完成；主配置与备份均可独立校验；损坏主配置不会静默覆盖或直接进入空 Workspace；用户确认后才提升备用配置；v1 JSON 可迁移到 v2；Direct2D/彩色 Emoji 不再是正式运行时依赖；Debug/Release 回归和性能门禁通过。

## 02. 归档范围、输入渲染与桌面交互性能 [x]

完成全日期归档搜索、开始/结束日期范围导出、Todo 日期面板遮挡与高度、可见高度统一驱动下方 Card 重排、自绘输入缓存与光标周期、Todo 悬停完整重绘消除，以及全局低级鼠标 Hook 与 UI 线程隔离。

退出条件：跨日期搜索可恢复结果；导出范围由两个自绘日期框选择且包含两端；日期面板不与添加行或正文重叠；所有可见高度变化保持下方 Card 8 DIP 间距；Todo 跨行悬停不触发完整 Card Render/Commit；同尺寸输入过程中不重复创建 DIB 和 D2D RenderTarget；低级鼠标 Hook 运行在独立消息线程；Debug/Release 回归与性能门禁通过。

## 03. Windows 10 图标兼容 [x]

设置页、桌面 Card 和自绘输入框不假定 Windows 11 的 `Segoe Fluent Icons` 必然存在；运行时检测字体能力，在 Windows 10 1809+ 回退到系统自带 `Segoe MDL2 Assets`，保证重命名、更多菜单、删除、卡片选项、导航和日期等图标入口可见。

退出条件：强制模拟 Fluent 字体缺失时选择 MDL2；Windows 10 回退字体包含关键重命名、更多、删除和折叠码位；Debug/Release 回归、性能门禁和安装包校验通过；真实 Windows 10 截图留待外部系统验收。

## 04. 引用集合安全与卡片锁定 [x]

References 根项目拖出只在 OLE 手势离开 Desto 后执行自绘移除映射确认；进入引用文件夹后允许对其中源文件进行普通拖放；文件删除统一使用自绘确认；锁定 Card 后禁止拖入、拖出、排序、重命名和删除，只保留打开。修复引用拖出默认 MOVE、经典菜单剪切、旧配置源文件变更默认开启、根文件夹误触发确认、取消后拖动状态失效和文件事务一致性风险。

退出条件：References 拖出不改变源路径；引用文件夹内容可按 Windows 文件语义操作；删除/移除映射确认可验证；锁定 Card 的所有修改入口均返回禁止；拖放、Shell 菜单、配置迁移回归测试通过。

## 05. 桌面触发与窗口层级 [x]

桌面和任务栏双击只接受严格空白命中；任务栏图标、托盘图标和窗口区域不触发。显示/隐藏窗口时不改变普通窗口前后台关系，不因宿主刷新把窗口错误置顶。

退出条件：空白判定覆盖 Windows 10/11 任务栏布局；普通窗口 Z 顺序回归通过；真实桌面场景待外部验收。

## 06. 发布候选验收

自动化安装包、升级包、首次运行、性能、资源和发布说明验收完成后，在真实桌面场景完成输入法、多显示器 DPI、任务栏/桌面双击、透明外观、Card 堆叠和长时间鼠标移动验证。正式发布仍需要根许可证、公开 GitHub 远程和代码签名证书；这些外部输入不能由代理代替用户决定。
