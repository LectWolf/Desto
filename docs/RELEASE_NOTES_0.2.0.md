# Desto 0.2.0

## Highlights

- Folder-source Mapping Cards support nested folder drops, sorting and shell refresh.
- Reference collections ask for confirmation when a referenced item is dragged out.
- Taskbar blank-area double-click returns only the corresponding display to the desktop.
- Card content uses large-icon grid presentation with compact spacing.
- About includes project access, update checking and Stable/Development update-channel switching.
- Stable versions use `major.minor.patch`; Development versions use `major.minor.patch.build`.
- In-app update checking queries GitHub Releases, retries a mirror, downloads the official
  installer and starts it after user confirmation.
- Project license is GPL-3.0-or-later with attribution and source-sharing requirements.

## Verification

- Release build completed on Windows x64.
- CTest: 24/24 passed.
- Installer manifest and SHA-256 checks are generated by the release workflow.
