# Application Card

## Ownership

Application Card 管理存储根下自己的相对目录。Explorer 拖入的文件或目录会被移动到该目录，而不是只保存外部路径。导入使用文件事务；同批任一移动失败时回滚已经完成的移动。

重名项目保留原扩展名并依次使用 `Name (1)`、`Name (2)`。已经位于 Card 目录内的项目不会重复移动，包含 Card 存储目录的上级目录不能被拖入，避免递归复制或移动自身。

## Shell Presentation

Windows Adapter 枚举 Card 目录并生成不可变项目视图：

- 普通文件和目录使用真实文件名（包含扩展名）与真实 Shell 图标。
- `.lnk` 标题忽略扩展名，并解析目标路径。
- 商店应用快捷方式读取 `PKEY_AppUserModel_ID`；图标优先从 `shell:AppsFolder` 的真实应用项提取。
- 缺失项目、不可解析快捷方式和图标不可用是不同状态。
- 图标不可用时不绘制 `FILE`、字母块或其他伪造图标；名称仍保留，项目仍可在可启动时打开。

默认不在图标下方显示文件名。项目槽位在鼠标悬停时显示轻量热点，停留约 600 ms 后显示文件名 Tooltip；失效项目追加简短状态，不显示完整文件路径。双击通过 Windows Shell 打开原始项目。

图标提供小、中、大、特大四档，默认大图标；显示尺寸依次为 20、26、34、44 DIP，网格步长依次为 37、44、55、74 DIP，不在步长之外重复增加间距。小和中从 Shell 请求系统小图标源（16 px），大和特大请求系统中图标源（32 px），再由宿主按当前 DPI 缩放到显示尺寸。每个项目只保留当前 Card 所需的一份源图，不为四档同时缓存。所有可点击图标都必须提供轻量 hover 热点和更明确的 pressed 反馈；当前项目图标和收缩 Chevron 使用同一交互规则。

宿主使用预乘 Alpha 双线性采样缩放 Shell 图标，避免最近邻放大造成的台阶边缘。实例在小/中与大/特大两组之间切换时重新解析目标源档位，并把项目、偏好和尺寸作为一批离屏画面提交；同组切换继续复用共享像素。

## Drag And Ordering

宿主使用 OLE `IDropTarget` 接收 Explorer 的 `CF_HDROP`，在 `DragOver` 阶段把卡片内容区内的任意指针位置连续映射到最近槽位；图标间距和左右留白不是禁止区。预选使用轻填充虚线框标出真实落点，只有槽位变化时才重绘。固定格数已满时才拒绝拖入。

自适应模式至少保留当前图标档位的建议列数；自定义布局由最右和最下占用槽位决定边界，而不是按项目数量截断落点。指针到达右侧外缘时预览新增一列，到达下侧外缘时新增一行；预览扩展后的边界会保留到指针明确移回内侧，因此可以从 `1x4` 连续扩到 `1x5` 或 `3x4`。拖放预览参与临时内容边界；由窗口扩张产生的 OLE `DragLeave/DragEnter` 抖动使用 90 ms 延迟清理吸收，成功 Drop 不提交“先缩回、再扩张”的中间帧。固定格数不参与自动扩缩。

Drop 在文件移动前完成 Shell 元数据准备并持有每张 Application Card 的内存项目快照。文件事务成功后只更新路径、纯内存布局和离屏画面，不再同步重新枚举目录或解析图标；成功提交后同时写入标准 OLE `Performed DropEffect` 并发送 Shell 移动/目录变更通知，使 Explorer 及时移除源项目。Desto 内部 Drop 另写完成标记，源卡的 `DoDragDrop` 返回后不会再执行第二次刷新。

项目按下后必须超过 Windows 系统拖动阈值才进入 `DoDragDrop`，因此单击和双击启动不会被误判为拖出。数据源提供 `CF_HDROP` 和首选移动效果；拖到 Explorer 后按返回效果重新枚举源 Card，同一卡片内 Drop 则复用同一路径完成排序。取消拖动不改变文件和顺序。

图标规格和名称显隐属于每个 Card 的内容偏好，不属于全局渲染常量。设置入口由事项 23 的主界面提供；当前宿主与快照已经消费并持久化这两个值。

空的展开 Application Card 保留与当前图标档位一行相同的内容高度，并显示轻量圆角虚线框和“拖放文件至此”；它不生成占位项目或伪造图标。Card 拖过显示器边界时按窗口与工作区的最大重叠选择目标屏幕，在 `WM_MOVING` 阶段立即按目标 DPI 重建位图和鼠标下的窗口尺寸，放置时只写回逻辑 DIP 尺寸及新的稳定 Display ID；跨 DPI 往返不会把像素宽高误存为逻辑尺寸。

## Rendering And Cost

Shell 图标在目录枚举时按需解析为 16x16 或 32x32 预乘 Alpha 像素，Card 的多屏 Projection 和运行期项目快照共享同一像素所有权，不重复保存图标位图。当前版本在启动、外部拖出和跨源档位切换时刷新；卡片内和卡片间移动优先使用内存增量更新。目录实时监听、增量失效和大目录缓存属于事项 27。
