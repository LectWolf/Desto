# TodoCard

TodoCard 保存稳定 ID、UTF-8 标题、完成状态、创建时间、完成时间、计划日期、显式归档状态和用户顺序。内容不依赖文件系统；切换完成状态和编辑标题不会隐式重排，只有用户拖动行才改变保存顺序。

## Commands And Validation

`ApplicationRuntime` 提供新增、重命名、切换完成、删除、完整顺序重排、归档全部已完成项目、归档单个已完成项目、恢复归档和实例偏好命令。每个命令先在副本上完成校验，再整体替换 TodoCard 内容：

- ID 必须非空且在 Card 内唯一。
- 标题必须包含可见字符，UTF-8 长度不超过 512 字节。
- 重排必须恰好包含当前全部 ID 且每个 ID 只出现一次。
- 缺失项目、重复 ID、空标题和不完整顺序会被拒绝，原状态与 Revision 不变。

成功变更只标记当前 Card，使用 Deferred 持久化；Snapshot 与当前 schema 27 配置按数组顺序保存全部待办字段，恢复时再次执行相同领域校验。旧配置迁移时为已完成但未显式归档的项目记录迁移时间，避免升级后突然消失。

## Native Interaction

设置页的小/中/大宽度档保存 4/5/6，并按 Large 图标网格映射为 244/299/354 DIP。schema 24 把旧 3/4/5 档迁移为 4/5/6，以保持原先选择的档位语义。

展开的 TodoCard 依次显示标题、操作行、新增行和当前日期内容。操作行日期入口短按在今天与明天之间快速切换；按住 500 ms 且指针仍位于入口时打开 Card 内完全自绘的 6×7 月历，可切换月份并选择任意日期，点击日历外关闭。双击不再打开月历。剩余数量是信息展示，不是按钮，不参与命中、筛选或高度变化，仅保留稳定背景以区分信息层级。单击抗锯齿圆形控件切换完成，超过系统拖动阈值后拖动排序，右键菜单删除；已存在待办不通过双击修改。普通事项正文使用 GDI `Segoe UI Variable Text`；检测到 Emoji 码点、VS16 或 ZWJ 时按需创建 DirectWrite 布局，并通过 Direct2D `ENABLE_COLOR_FONT` 绘制 Windows 彩色 `Segoe UI Emoji`。测量与绘制使用同一字体尺寸和换行宽度，失败时才回退 GDI 单色路径；普通文字不会启动该系统组件路径。不使用悬停 Tooltip；创建时间可按实例显示，默认关闭。

勾选待办时记录绝对完成时间；完成日期仍是设置时区中的当天时继续显示，日期变化后自动进入归档。标题栏归档入口把已完成项目显式标记为归档并立即隐藏，不删除数据；恢复项目会把完成时间更新为恢复时间，因此不会立刻再次自动归档。

设置页的卡片内容预览只投影未归档项目，并保留独立滚动位置。已完成但尚未归档的项目仍然可见，可从预览中逐项归档；显式归档和按完成日期自动归档的项目只出现在归档页。归档页按设置时区把完成时间换算为自然日，默认选中昨天，可逐日向前或回到今天；点击日期标签打开完全自绘的月份面板，含月份切换、星期头、6×7 日期格、今天/选中/非本月/未来状态，未来日期不可选。选择日期后关闭面板并重置列表滚动；Escape、点击外部或切页也关闭，不使用 `MONTHCAL_CLASS` 或系统 DatePicker。搜索有内容时遍历所有归档自然日，不受当前日期筛选限制；清空搜索后恢复只展示选中日期。兼容数据缺少完成时间时使用创建时间，两个时间都缺失的项目不伪造日期。恢复和永久删除回调都以 Card ID 与 TodoItem ID 作为稳定身份；回调同步刷新整张 Card 后，设置页重新按 ID 查找，不复用回调前索引或引用。无结果面板固定为 88 px 高，避免空状态占用过多纵向空间。

文本输入使用按需创建的 `WindowsTextInput` 自绘弹出窗口。每个编辑器只有一个 HWND，不创建原生 Edit 或额外绘制宿主；窗口自己持有 UTF-16 文本、选区、撤销、剪贴板和组合输入状态，通过 TSF `ITextStoreACP` 接入 Windows 中文输入法并提供候选框光标矩形。DirectWrite 的同一个单行布局负责普通文字、彩色 Emoji、测量、鼠标命中、选区、组合串下划线和光标，避免显示位置与真实编辑位置分叉。Popup 按当前尺寸持久复用一套 DIB、Memory DC 和 D2D DC RenderTarget，文本布局只在文字、样式或尺寸变化时失效；同一消息周期内由 TSF 产生的文字、选区和组合串变化通过私有窗口消息合并为一次 `UpdateLayeredWindow` 提交，避免输入时整框连续刷新。输入和选区变化把光标置为可见并重新开始 530 ms 闪烁周期。尺寸变化或窗口销毁时释放缓存。提交时以严格 Win32 转换保存为 UTF-8，非法文本不进入领域回调；Enter 或失焦提交，Escape 取消。弹层关闭后立即销毁，Card 窗口继续使用 `WS_EX_NOACTIVATE`，因此非编辑状态没有额外窗口、焦点和常驻成本。同一 Card 的多屏 Projection 在一次领域变更后同步更新内容与高度。

编辑器不使用 Card 的 owner 关系；获得输入焦点后，编辑器和 Card 会按顺序恢复到普通应用窗口之后，避免 Windows 把整个拥有者窗口组提升到前台。普通应用始终覆盖 Card 和临时编辑器。

## Historical archive entry and export

归档页提供历史补录。入口打开设置窗口内的自绘浮层，选择一个 Todo Card、输入内容，并以归档页当前选中日期作为完成/归档日期；嵌入式 `WindowsTextInput` 自己处理 TSF 输入法、Emoji、撤销、剪贴板、圆角底板、文字、选区和光标。领域命令直接创建 `completed=true`、`archived=true` 的 TodoItem，创建时间与完成时间取所选自然日中午，避免时区边界把条目投影到相邻日期。没有 Todo Card、空内容或非法日期时不写入。

导出浮层提供开始日期和结束日期两个自绘日期框。打开时默认以归档页当前日期为结束日、向前 6 天为开始日；点击任一日期框后在同一浮层绘制月份导航、星期头和 6×7 日期格。选择开始日晚于结束日时同步把结束日推进到开始日，选择结束日早于开始日时同步把开始日退到结束日，保证范围始终有效并包含两端。确认后用 Windows 保存文件对话框选择 `.txt` 位置；输出使用 UTF-8 BOM、CRLF、Card 分组和每条归档的自然日，包含显式归档及按完成日期进入归档的兼容条目，且不修改任何 Todo 数据。用户取消时不创建文件，打开或写入失败记录 `settings.archive_export_failed`。

待办行直接绘制到 Card 现有离屏位图，不为每一行创建 HWND。普通行只更新内存中的命中索引，不绘制逐行 hover，因此鼠标在行之间快速移动不会创建字体、布局、覆盖层或调用 `UpdateLayeredWindow`；按钮、按下、复选框和拖动状态仍按交互需要重绘。常驻增量仅为 TodoItem 文本和少量交互状态；编辑控件只在用户输入期间存在。DirectWrite/Direct2D 工厂只在首次遇到 Emoji 时按需初始化，不建立合成树或逐行对象。内容高度按逐项元数据和完整换行后的事项高度计算；日期月历打开时先清除面板范围内已有内容，再把面板、选中底色、今天描边和文字绘制到同一预乘内容层，Card 高度至少 380 DIP；外观 5 使用蓝灰水晶面板、白色描边和高对比日期色。空 Card 仍保留新增行，收起状态只提交标题区域。
