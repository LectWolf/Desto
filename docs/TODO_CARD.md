# TodoCard

TodoCard 保存稳定 ID、UTF-8 标题、完成状态、创建时间、计划日期、归档状态和显式用户顺序。内容不依赖文件系统；切换完成状态和编辑标题不会隐式重排，只有用户拖动行才改变保存顺序。

## Commands And Validation

`ApplicationRuntime` 提供新增、重命名、切换完成、删除、完整顺序重排、归档已完成项目、恢复归档和实例偏好命令。每个命令先在副本上完成校验，再整体替换 TodoCard 内容：

- ID 必须非空且在 Card 内唯一。
- 标题必须包含可见字符，UTF-8 长度不超过 512 字节。
- 重排必须恰好包含当前全部 ID 且每个 ID 只出现一次。
- 缺失项目、重复 ID、空标题和不完整顺序会被拒绝，原状态与 Revision 不变。

成功变更只标记当前 Card，使用 Deferred 持久化；Snapshot 与 schema 6 配置按数组顺序保存全部待办字段，恢复时再次执行相同领域校验。旧配置迁移时为缺失字段补默认值。

## Native Interaction

展开的 TodoCard 在首个事项上方固定显示一行新增区，并提供“今日/明日”切换。标题显示当前可见数量；事项按计划日期分组，今日未完成项跨零点后继续显示为昨日、前日或具体日期。单击抗锯齿圆形控件切换完成，单击文字编辑，超过系统拖动阈值后拖动排序，右键菜单删除。事项正文完整换行，不使用悬停 Tooltip；创建时间可按实例显示，默认关闭。

标题栏归档入口把已完成项目标记为归档并立即从卡片隐藏，不删除数据。恢复入口属于设置主界面；时区在该界面交付前跟随系统时区，后续由全局时区设置解析当前日期。

文本输入使用按需创建的无边框原生 Edit 弹层：Enter 或失焦提交，Escape 取消。弹层关闭后立即销毁，Card 窗口继续使用 `WS_EX_NOACTIVATE`，因此非编辑状态没有额外窗口、焦点和常驻控件成本。同一 Card 的多屏 Projection 在一次领域变更后同步更新内容与高度。

## Rendering And Cost

待办行直接绘制到 Card 现有离屏位图，不为每一行创建 HWND。常驻增量仅为 TodoItem 文本和少量交互状态；编辑控件只在用户输入期间存在。内容高度按日期标题和完整换行后的事项高度计算；空 Card 仍保留新增行，收起状态只提交标题区域。
